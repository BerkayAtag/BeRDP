Ağ erişimi ve firewall kuralları

BeRDP servisleri yalnız 127.0.0.1 üzerinde dinler. İstemciler ve tarayıcılar sunucuya kurumunuzun TLS reverse proxy'si üzerinden HTTPS ile bağlanır; 5001 ve 5173 portlarını dış ağa açmayın.

1. İstemci, sunucu ve RDP hedefleri

Kaynak Hedef Protokol Port Açıklama Durum
İstemci ve yönetici ağları TLS reverse proxy (BeRDP sunucusu) TCP 443 HTTPS API (/api), yönetim konsolu, Windows SSO ve SignalR WebSocket Zorunlu
Aynı sunucudaki proxy BeRDP API / konsol TCP 5001 / 5173 Yalnız loopback (127.0.0.1); dış ağa açılmaz Yerel
İstemci ağları RDP hedefleri (VM/PC) TCP 3389 Windows Uzak Masaüstü bağlantısı (mstsc) Zorunlu
İstemci ağları RDP hedefleri (VM/PC) UDP 3389 RDP UDP taşıması: daha akıcı görüntü ve ses Önerilen
BeRDP sunucusu RDP hedefleri (VM/PC) TCP 3389 "RDP erişilebilir" durum kontrolü (TCP bağlantı denemesi) Önerilen

2. BeRDP sunucusu ve Active Directory

Yalnız AD entegrasyonu açıksa gereklidir. Kesin kuralları kurumunuzun AD topolojisine göre belirleyin; geniş Any kuralları oluşturmayın.

Kaynak Hedef Protokol Port Açıklama
BeRDP sunucusu Domain DNS TCP / UDP 53 DNS çözümleme ve DC keşfi (SRV)
BeRDP sunucusu Domain Controller TCP / UDP 88 Kerberos kimlik doğrulama
BeRDP sunucusu Domain Controller TCP / UDP 389 LDAP / CLDAP sorguları ve kullanıcı arama
BeRDP sunucusu Global Catalog TCP 3268 Global Catalog sorguları
BeRDP sunucusu Domain Controller TCP 135, 49152-65535 RPC; grup üyeliği ve NetLogon sorguları

3. Hızlı bağlantı kontrolleri (PowerShell)

# BeRDP HTTPS adresini test et (TCP 443)
Test-NetConnection -ComputerName "berdp.example.test" -Port 443

# RDP hedef makine erişimini test et (TCP 3389)
Test-NetConnection -ComputerName "vm01.example.test" -Port 3389

# Active Directory LDAP erişimini test et (TCP 389)
Test-NetConnection -ComputerName "dc01.example.test" -Port 389

Kurulum ve kaldırma

Setup dosyaları çift tıklayıp Kur diyerek kurulur. Aşağıdaki komutlar SCCM, Intune veya GPO ile sessiz dağıtım içindir. İmzasız paketlerde SmartScreen uyarısı görülebilir.

1. İstemci sessiz kurulum

Kullanıcı bilgisayarları (masaüstü kısayolu ile):

BeRDP.Client.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /TASKS="desktopicon" /BACKENDURL="https://berdp.example.test/api" /SSO=0 /LOG="%TEMP%\BeRdpClientInstall.log"

Windows SSO yalnız domain DNS adı ve doğrulanmış Kerberos ortamında /SSO=1 ile açılmalıdır. RDP hedefi olarak kullanılacak iş istasyonları için /TASKS="desktopicon,rdphost" /RDPNETWORKS="10.20.0.0/16" /RDPPORT=3389 eklenebilir; merkezi GPO ile yönetilen makinelerde kullanmayın.

2. İstemci sessiz kaldırma

"C:\Program Files\BeRDP\Client\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

3. Sunucu sessiz kurulum

Yönetici yetkisiyle çalıştırın. Sessiz kurulumda ilk yönetici sorulmaz; ardından sunucuda yönetici PowerShell ile oluşturun:

BeRDP.Server.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /SSO=0 /LOG="%TEMP%\BeRdpServerInstall.log"

cd "C:\Program Files\BeRDP\Server\Backend"
.\BeRdp.Backend.exe --bootstrap-admin kurum-admin

4. Sunucu sessiz kaldırma

"C:\ProgramData\BeRDP\Server\Uninstall\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Sunucu kaldırılırken veritabanı (berdp.db) ve anahtar yedekleri veri kaybını önlemek için silinmez.

5. Yükseltme

Önce veritabanı, yapılandırma ve DataProtectionKeys yedeğini alın. Yeni setup dosyalarını eski sürümü kaldırmadan çalıştırın; mevcut ayarlar, anahtarlar ve hesaplar korunur.

Sunucuda:
BeRDP.Server.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-

İstemcilerde:
BeRDP.Client.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-
