Ağ Erişim & Firewall Kuralları

BeRDP Sunucu, İstemci, RDP Hedefleri ve Active Directory arasındaki gerekli port ve protokol izinleri.

1. İstemci ◄► Sunucu ve RDP Hedefleri Trafiği

Kaynak Hedef Protokol Port Açıklama Durum
İstemci VLAN'ları BeRDP Sunucusu TCP 5001 REST API, Login, Negotiate SSO ve SignalR WebSocket kanalı Zorunlu
Yönetici & Portal Ağları BeRDP Sunucusu TCP 5173 Web Yönetim Paneli ve Kullanıcı Portalı Zorunlu
İstemci VLAN'ları RDP Hedefleri (VM/PC) TCP 3389 Standart RDP Uzak Masaüstü Bağlantısı Zorunlu
İstemci VLAN'ları RDP Hedefleri (VM/PC) UDP 3389 RDP 8.0+ Yüksek Performans Akıcı Görüntü/Ses Taşıması Önerilen
BeRDP Sunucusu RDP Hedefleri (VM/PC) TCP 3389 Anlık RDP Erişilebilirlik (Online/Offline) Probe Kontrolü Önerilen

2. BeRDP Sunucusu ◄► Active Directory (Domain Controller) Trafiği

Kaynak Hedef Protokol Port Açıklama Durum
BeRDP Sunucusu Domain DNS TCP / UDP 53 DNS Çözümleme ve DC Keşfi (SRV Sorguları) Zorunlu
BeRDP Sunucusu Domain Controller TCP / UDP 88 Kerberos Kimlik Doğrulama Servisi Zorunlu
BeRDP Sunucusu Domain Controller TCP / UDP 389 LDAP / CLDAP Dizin Sorguları ve Kullanıcı Arama Zorunlu
BeRDP Sunucusu Global Catalog TCP 3268 Active Directory Global Catalog Sorguları Zorunlu
BeRDP Sunucusu Domain Controller TCP 135 RPC Endpoint Mapper (AD Grup sorguları) Zorunlu
BeRDP Sunucusu Domain Controller TCP 49152 - 65535 Windows Dinamik RPC Aralığı (NetLogon / LSA) Zorunlu

3. Hızlı Güvenlik Duvarı Kontrol Komutları (PowerShell)

Yönetici PowerShell terminalinde aşağıdaki komutlarla port erişimlerini doğrulayabilirsiniz:

# BeRDP Backend API erişimini test et (TCP 5001)
Test-NetConnection -ComputerName "sunucu-ip" -Port 5001

# RDP Hedef Makine erişimini test et (TCP 3389)
Test-NetConnection -ComputerName "vm01.example.test" -Port 3389

# Active Directory LDAP erişimini test et (TCP 389)
Test-NetConnection -ComputerName "dc01.example.test" -Port 389

BeRDP Sessiz Kurulum & Kaldırma Rehberi

Kurumsal ortamda (SCCM / Intune / GPO) kullanılabilecek sessiz kurulum ve kaldırma komutları. Kurulum parametreleri ve yapılandırması için docs/INSTALLATION_GUIDE.md dosyasına bakınız.

1. İstemci (Client) Sessiz Kurulum Komutları

Normal Kullanıcı Bilgisayarları (SSO ve Desktop Icon ile):

BeRDP.Client.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /TASKS="desktopicon" /BACKENDURL="https://berdp.example.test" /SSO=1 /LOG="%TEMP%\BeRdpClientInstall.log"

RDP Hedefi Olarak Kullanılan İş İstasyonları (RDP Host, AVC444 ve Firewall Kuralları ile):

BeRDP.Client.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /BACKENDURL="https://berdp.example.test" /SSO=1 /TASKS="desktopicon,rdphost" /RDPNETWORKS="10.20.0.0/16,10.30.10.0/24" /RDPPORT=3389 /LOG="%TEMP%\BeRdpHostInstall.log"

2. İstemci (Client) Sessiz Kaldırma Komutu

"C:\Program Files\BeRDP\Client\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

3. Sunucu (Server) Sessiz Kurulum Komutu

Yönetici haklarıyla (Elevated CMD) çalıştırılmalıdır:

BeRDP.Server.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP- /SSO=1 /CLIENTNETWORKS="10.20.0.0/16,10.30.10.0/24" /PORTALNETWORKS="10.20.0.0/16,10.30.10.0/24" /LOG="%TEMP%\BeRdpServerInstall.log"

4. Sunucu (Server) Sessiz Kaldırma Komutu

"C:\ProgramData\BeRDP\Server\Uninstall\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Sunucu kaldırılırken veritabanı (berdp.db) ve anahtar yedekleri veri kaybını önlemek için silinmez.

5. Güncellemeler ve Yükseltme (In-Place Upgrade)

Mevcut servisleri durdurmadan veya eski sürümü kaldırmadan yeni setup dosyalarını doğrudan çalıştırın:

Sunucuda:
BeRDP.Server.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-

İstemcilerde:
BeRDP.Client.Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /SP-
