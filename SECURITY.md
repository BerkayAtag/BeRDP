# Security policy

Supported version: the latest release (1.7.0). Review [deployment requirements](docs/INSTALLATION_GUIDE.md) and [validation limits](docs/VALIDATION.md) before production adoption.

**Private vulnerability reporting** is enabled. Report sensitive findings through [Report a vulnerability](https://github.com/BerkayAtag/BeRDP/security/advisories/new) (Security → Advisories). do not publish passwords, tokens, personal data or exploit details in a public issue. No response SLA or dedicated mailbox is claimed.

Include affected version, configuration, reproduction using synthetic data, expected/observed behavior and impact. Test only systems you own or are authorized to assess. Dependencies and bundled runtimes require regular rebuilds; self-contained installers do not receive runtime patches merely because the host .NET installation changes.
