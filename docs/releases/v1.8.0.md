# BeRDP 1.8.0

Windows RDP kimlik doğrulaması ve kurumsal politika uyumluluğu düzeltmeleri.

- RDP varsayılan olarak Windows kimlik ekranıyla açılır. BeRDP artık oturum parolasını saklamaz veya Credential Manager kaydı oluşturup değiştirmez. Yerel BeRDP parolası hedef Windows hesabına gönderilmez.
- Makine bazında isteğe bağlı Remote Credential Guard: mevcut Windows kimliği, tam DNS adı ve Kerberos gerektirir. API SSO ayarından bağımsızdır; otomatik güvenlik düşürmesi yoktur.
- Ağ kalitesi otomatik seçilir, kısa kesintilerden sonra mstsc yeniden bağlantısı etkindir. Çift tıklama sırasında yinelenen yetki isteği engellenir.
- Makine durumu istemciyle aynı DNS hedefini kullanır. AD parola girişi kayıtlı UPN ile doğrulanır. Süresi dolan SignalR bağlantıları kapatılır; giriş penceresi kapatıldığında keşif ve giriş istekleri iptal edilir.
- Windows grafik/transport politikalarına yazan eski `rdphost` kurulum görevi kaldırıldı. Eski dağıtım komutlarında bu görev çıkarılmalıdır; var olan GPO değerleri otomatik silinmez.
- Tanıtım sayfasının mevcut tasarımı korunmuştur. CI, paket kabulüne ek olarak gerçek HTTP ve tarayıcı regresyon testlerini çalıştırır.

## Kurulum ve doğrulama

Server ve Client paketlerini birlikte güncelleyin. Sunucuyu yükseltmeden önce veritabanı, yapılandırma ve DataProtectionKeys için tutarlı yedek alın. Paketler başarılı Validate BeRDP çalışmasının çıktılarından yayımlanır; `SHA256SUMS.txt` ve `installation-verification.json` ektedir.

Paketler Authenticode imzalı değildir. Gerçek AD/Kerberos, hedef VM, NLA, kuruma özgü GPO/EDR ve eski üretim verisiyle yükseltme kurum pilotunda doğrulanmalıdır. Hiçbir uygulama, Windows'un açıkça yasakladığı RDP erişimini sorunsuz hale getirme garantisi veremez. BeRDP bu politikaları gevşetmez.
